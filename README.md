# Money Pilot V2 — Offline-first Personal Finance Super App

## Included
- Existing Money Pilot finance/accounting tools and saved-data format retained.
- DOB/name onboarding screen and startup lock gate hidden; stored profile/PIN keys are not deleted.
- First-launch Welcome Tour with replay option in Finance Hub.
- Finance Hub summary, monthly spending category insights and separate monthly expense limit.
- Full browser-localStorage JSON backup. Safe restore imports only missing keys and leaves existing keys unchanged.
- PWA assets, manifest, install support and service-worker cache version bumped to V3.
- Existing app features include transactions, reports, budgets, charts, recurring entries, goals, bank/cash, loans, reminders, backup tools, AI/voice helpers and student-finance utilities. Availability of browser AI/voice features depends on browser support.

## Important data safety
- This app does not clear localStorage or migrate/delete existing accounting records in this release.
- Before replacing a live file, download a full backup from the current app if possible.
- Keep a copy of the old `index.html` and current `sw.js`.
- Cloud sync is **not configured** in this ZIP. A real cloud backend requires credentials, authentication and security rules; never put secret service keys in client-side code.
- The app's older built-in backup restore may replace the active dataset. The new Finance Hub safe restore instead adds only missing localStorage keys.

## GitHub Pages update
1. Extract this ZIP.
2. Upload/replace the files at the repository root, including `index.html`, `sw.js`, `manifest.json`, icons and `.nojekyll`.
3. Commit changes and wait for GitHub Pages to deploy.
4. Open the website in Chrome and test it before relying on the installed PWA.
5. The service worker cache version is bumped to V3 to encourage the new app shell to load. Browser localStorage is separate and is not intentionally erased.

## Android package
This ZIP includes the existing Capacitor config/package files as a starter. An APK is not generated by this ZIP; Android build tooling and a local build are still required.
