# Money Pilot — Business Intelligence 2.0 (Web + Android scaffold)

This package preserves the supplied Money Pilot HTML app and adds eight Business Intelligence 2.0 modules:

1. AI Business Analyst (local rule-based calculations and recommendations)
2. Barcode / QR Billing (browser BarcodeDetector where supported; manual input fallback)
3. Outstanding Control Center (Udhaar + supplier purchase balances)
4. Advanced Inventory (batches, expiry dates, barcode, reorder levels, stock movements)
5. Bank Reconciliation (CSV import and manual matching)
6. Audit Trail & Staff Roles (local activity log and role labels)
7. Offline & Sync (PWA shell cache, JSON sync export and merge-import)
8. CA Export Center (multi-sheet XLSX workbook)

## Run the web app

For a quick local preview, install Node.js and run:

```bash
npm install
npm run web:serve
```

Open `http://localhost:4173`. For installation as a PWA on Android, host the `www` folder on an HTTPS website, then open it in Chrome and use **⋮ → Install app / Add to Home screen**. Service workers do not run from `file://` URLs.

## Create the Android project

Prerequisites: Node.js, Android Studio, Android SDK, and a JDK supported by your installed Android Studio/Gradle version.

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

In Android Studio, allow Gradle sync, select a device/emulator, then Run. To create an APK, use **Build → Build Bundle(s) / APK(s) → Build APK(s)**. The `android/` native project is generated by Capacitor on your computer; it is intentionally not represented as a prebuilt APK here.

## Important integration / production gaps

- **Cloud sync / multi-device sync:** this version exports and merges JSON bundles locally. A hosted backend, account authentication, conflict resolution and encrypted transport/storage are required for automatic cloud sync.
- **AI Business Analyst:** this is local rule-based analysis, not an LLM-powered AI service. For advanced AI, add a secure backend; never embed a private API key in this HTML.
- **Barcode / QR:** live camera scanning requires a supported browser/device and camera permission; some browsers only support certain barcode formats. Manual code entry is included.
- **Bank reconciliation:** imports CSV statements only; no direct bank API connection. Review suggested matches manually.
- **Audit trail / staff roles:** records are stored in browser localStorage and can be modified by someone with device/devtools access. These are not tamper-proof audit logs or secure user permissions. Server-side authentication and authorization are needed for production.
- **Offline:** core data is local-first. The PWA shell is cached after the first successful HTTPS load. PDF/Excel libraries use CDN scripts and may need a successful online load before they are available offline.
- **Accounting/GST:** exports are working bookkeeping aids, not a GST return filing, tax advice, or audited financial statements. Verify totals, classifications and GST treatment with your CA.
- **Existing storage:** data remains in each browser profile's localStorage. Keep JSON backups before switching devices, clearing browser data, or upgrading.
